# CRVpaper2026
The study data and analysis scripts for the Waugh et al., original CRV paper


First, download each study's folder to computer

The resulting results files are too large to host on github, so you have to rerun
the analyses from scratch. Therefore, the resulting numbers may be a little different
than those presented in the MS.
If you feel like they are too different, then feel to reach out and we can provide the original
results file.

To run analyses from scratch:

1. Change working directory in "Models_stan_master_XXXXXXX.R" to match your computer's directory
2. Run that script
3. You should now see several 'results_XXXX_X' files in the directory.
3. Change working directory in "ModelStats_XXXXX.R" and run that script to get manuscript analyses
